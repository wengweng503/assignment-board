# 作业截止日期看板（项目 3）

一个管理作业与截止时间的小系统，使用纯 HTML + CSS + JavaScript 实现，无需框架、无需联网、无需登录。

## 功能

- 添加 / 编辑 / 删除作业（每条包含课程、标题、截止时间、完成状态）
- 按截止时间自动排序
- 自动区分状态：**即将到期（48 小时内）**、**已逾期**、**已完成**、进行中
- 数据保存在浏览器本地存储（localStorage），刷新后仍在
- 删除前二次确认 + 5 秒内可撤销
- 移动端适配：表单不超屏、按钮适合手指点击、不依赖鼠标悬停
- 进阶功能：JSON 导出 / 导入，可手动在不同设备之间迁移数据
- 明确提示「数据仅保存在当前浏览器，不与其他设备同步」

## 启动方式（电脑）

在 `index.html` 所在目录运行以下任一命令，让服务监听 `0.0.0.0` 以支持手机访问：

```bat
python -m http.server 8000 --bind 0.0.0.0
```

或双击运行 `start-server.bat`。

## 手机访问

1. 让电脑和手机连接同一个 Wi-Fi（或个人热点）。
2. 查看电脑的局域网 IP（如 `192.168.1.23`）。
3. 手机浏览器打开：

```text
http://192.168.1.23:8000
```

（不要用 `localhost`，那只能在本机访问。）

## 停止服务

在运行服务的窗口按 `Ctrl + C`，或直接关闭该窗口。

## 测试清单（建议）

- 添加一条作业 → 列表出现并自动排序
- 编辑作业 → 内容更新
- 勾选完成 → 状态变为「已完成」并变灰
- 删除 → 弹出确认 → 确认后可撤销
- 刷新页面 → 记录仍在（同一浏览器）
- 导出 JSON → 得到一个 `.json` 文件；导入 → 记录被替换
- 手机上重复以上操作，确认表单不超屏、按钮可点
